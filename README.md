# Introduction to Robot Operating System 2

A browser-based slide deck for the three-day **Hands-on Training on ROS 2 Middleware - Phase I**, scheduled for 2-4 November 2026.

The deck follows the supplied programme and, within each block, the order of the official ROS 2 Jazzy tutorials. It covers:

- Prerequisites: essential Linux terminal commands and Python basics, with self-checks
- Installing ROS 2 Jazzy, configuring the environment (domain ID, discovery range), and ros2 doctor, plus a common setup problems checklist
- What ROS 2 is, the history of ROS and ROS 2, and ROS 1 vs ROS 2
- ROS 2 architecture, client libraries (rclcpp, rclpy, rcl), DDS and its implementations, and QoS
- Nodes and remapping, topics, messages, rosdep, custom msg and srv files, first rclpy publisher and subscriber
- Services and actions with Python servers and clients, custom action interfaces, parameters in a node, package anatomy, timers, logging and rqt_console, launch, and ros2 bag
- TF2, URDF, robot_state_publisher, RViz2, Gazebo Harmonic, and sensor simulation
- Optional slides (eyebrow marked "Optional"): C++ publisher and subscriber, executors and callback groups, launch arguments, event handlers, XML and YAML launch files, and tf2 static, broadcaster, and listener code
- Going further chapter: composition, managed lifecycle nodes, testing with colcon, and SROS2 security
- Manipulator fundamentals, forward and inverse kinematics, ros2_control, MoveIt 2, motion planning, Cartesian motion, and grasping

## View locally

No build step or package installation is required.

```bash
python3 -m http.server 8000
```

Open <http://localhost:8000>.

## Presentation controls

| Key | Action |
| --- | --- |
| Space / Right | Reveal the next teaching step or advance |
| Left | Hide the previous step or return to the previous slide |
| G | Choose a slide from the list (or use the menu at the top right) |
| K | Pause or resume the animation on this slide |
| R | Restart the animation on this slide |
| O | Slide overview |
| N | Speaker notes |
| F | Fullscreen |
| P | Print or save as PDF |
| ? | Shortcut help |

Printing (P) freezes every animation on its finished frame so the PDF shows complete terminals and diagrams.

Each slide has a stable URL hash such as `#12`, so links can open a specific slide.

The history of ROS, every ROS 2 distribution since 2017, ROS 1 vs ROS 2 architecture, communication, parameters, launch, ros2 bag, TF2, URDF, and the Gazebo loop are shown as looping animations, including animated turtlesim demos with typed terminal commands for topics, services, actions, parameters, launch, and ros2 bag. Complex concepts also use progressive reveals so the presenter can explain one stage at a time. Motion automatically reduces when the operating system's **Reduce Motion** preference is enabled.

## Interactive 3D scenes

Fourteen slides contain interactive scenes built with three.js (`scenes3d.js`): launching a robot model with robot_state_publisher, joint_state_publisher, and RViz, TF2 frames on a driving TurtleBot3, a TF tree explorer for any lookup_transform, rotations and quaternions, assembling the Franka Panda URDF, simulation time, a lidar in a room, joint and task space, inverse kinematics, ros2_control tracking, RRT-Connect planning, time parameterization, joint vs Cartesian motion, and pick and place. Drag to orbit and scroll to zoom; K pauses and R restarts.

The robot models come from ROS 2 Jazzy packages (`assets/robots/SOURCES.txt`), and three.js and urdf-loader are copied into `vendor/`, so the deck works without internet. Numbers shown in the scenes (forward kinematics, IK results, quaternions) were checked against tf2 on Jazzy.

## Edit the animations

The animated diagrams (ROS 2 equation, ROS 1 vs ROS 2, client libraries, topics, services, actions, turtlesim demos, TF2, URDF, and the Gazebo loop) are generated by one script. Edit the slide definitions in `tools/animations/build.py`, then regenerate:

```bash
python3 tools/animations/build.py
```

The script finds each slide by its title and rewrites it in `index.html`; review the diff before committing. Use `--check` to confirm `index.html` matches the script. Text on slides the script does not own can still be edited directly in `index.html`.

## Publish with GitHub Pages

The included workflow publishes the repository root whenever `main` is updated.

1. Push the repository to GitHub.
2. Open **Settings > Pages** in the GitHub repository.
3. Under **Build and deployment**, select **GitHub Actions**.
4. Open the workflow run under **Actions** and wait for deployment to finish.

The site will be available at:

<https://runtimerobotics.github.io/ros2_workshop_slides/>
