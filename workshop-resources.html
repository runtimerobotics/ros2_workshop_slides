ROS 2 Robotics Workshop

A complete, hands-on learning pathway—from Linux and programming foundations to robot simulation, perception, motion planning, and vision-guided manipulation.

Learn ROS 2 by building real robotic applications

This workshop combines structured training slides, a beginner-friendly ROS 2 setup experience, and practical code that runs on ROS 2 Jazzy (Ubuntu 24.04) and ROS 2 Lyrical (Ubuntu 26.04). The examples are continuously built and tested for both releases.

What you will build

ROS 2 publishers, subscribers, services, actions, parameters, and launch files
Python and C++ robotics applications with custom interfaces
TF2 coordinate frames and Turtlesim programming exercises
Robot models using URDF and Xacro
Gazebo simulation with RGB-D, LiDAR, IMU, force-torque, and contact sensors

MoveIt 2 planning, inverse kinematics, and collision-aware motion
