The ROS equation

What is ROS 2?

ROS 2= Plumbingnodes, topics, services, actions, discovery, QoS+ Toolsros2 CLI, RViz2, rqt, ros2 bag, launch, Gazebo+ CapabilitiesNav2, MoveIt 2, ros2_control, TF2, perception+ Communitydocs, Q&A, Discourse, package index, ROSCon

ROS 2 is not an operating system. It is open-source middleware, libraries, and tools that run on top of Linux, Windows, macOS, and RTOS targets.

Reveal one term at a time; the next four slides animate each term. The point: participants reuse plumbing, tools, and capabilities so they can focus on their robot's unique problem.

Why a new version

Why ROS 2?

01No single point of failure

ROS 1 needed a central master. ROS 2 nodes discover each other directly.

02Real products

Security, real-time support, lifecycle nodes, and long-term support releases.

03Real networks

QoS handles lossy Wi-Fi, multiple robots, and high-rate sensor data.

04More platforms

Linux, Windows, macOS, and microcontrollers through micro-ROS.

ROS 1 reached end of life in May 2025. New projects should start on ROS 2.

ROS 1 was designed for research with one robot, a reliable network, and a single workstation. Those assumptions do not hold in fleets, factories, or embedded products, so ROS 2 was redesigned rather than patched.

Centralized vs distributed

ROS 1 vs ROS 2 architecture

registration / datamaster replyconnectfailed lookup
Let the left side reach step 4 and ask: what happens to a robot in the field if roscore crashes? Existing ROS 1 connections survive, but nothing new can start. ROS 2 has no roscore command at all.

Layer by layer

ROS 1 vs ROS 2 software stack

In ROS 1, roscpp and rospy were separate implementations, so features and bugs differed by language. In ROS 2, rcl is shared and rmw lets you swap the middleware without touching your code.

Python · 2 of 3

Classes and objects

class Robot:
    def __init__(self, name):
        self.name = name        # attribute
        self.speed = 0.0

    def drive(self, speed):    # method
        self.speed = speed
        print(f'{self.name}: {speed} m/s')

class Rover(Robot):            # inherits Robot
    def __init__(self):
        super().__init__('rover')

r = Rover()
r.drive(0.3)

Every ROS 2 node is a class

  • __init__ runs when the object is created
  • self is the object itself
  • Rover(Robot) reuses everything in Robot
  • super().__init__ sets up the parent

Your nodes write class Talker(Node) and call super().__init__('talker').

Spend the most time here. Participants who understand self and inheritance will read every rclpy example without trouble.

Python · 3 of 3

Imports and callbacks

import math
from std_msgs.msg import String   # from a package

def on_message(text):
    print('received:', text)

def subscribe(callback):
    # the caller decides what happens later
    for text in ['hello', 'world']:
        callback(text)

subscribe(on_message)   # pass the function, no ()

def main():
    print(math.pi)

if __name__ == '__main__':
    main()

The callback idea

  • import brings in code from other packages
  • A callback is a function you hand to someone else
  • ROS calls it when a message, timer, or request arrives
  • main() is the entry point ros2 run starts

subscribe(on_message()) calls it immediately. Pass on_message without brackets.

This is the bridge to create_subscription(String, 'chatter', self.on_msg, 10) and create_timer(0.5, self.tick).

Self-check: Python

  1. Write a Robot class with a name and a battery level.

class Robot:
    def __init__(self, name, on_change):
        self.name = name
        self.battery = 100
        self.on_change = on_change

    def drive(self):
        if self.battery if self.battery < 20:lt;= 20:
            print('battery low')
            return
        self.battery -= 10
        self.on_change(self.battery)

r = Robot('rover', lambda b: print(f'battery {b}%'))
for _ in range(10):
    r.drive()

rclcpp and rclpy are the two officially supported libraries. Both are thin layers over the same C library, rcl, so behavior is consistent and a Python node talks to a C++ node with no extra work.

Data Distribution Service

What is DDS?

  • An open standard from the Object Management Group (OMG)
  • Data-centric publish-subscribe
  • Automatic discovery with no broker
  • Rich Quality of Service policies
  • Wire protocol: RTPS over UDP
  • Proven in defense, aerospace, and finance
Noderclcpp / rclpyyour code
rcl + rmwROS middleware APIhides the vendor
DDSGlobal data spacediscovery, QoS
RTPSUDP / shared memoryon the wire

ROS 2 did not invent a new transport. It reused an industrial standard and put the rmw layer in front of it.

Because rmw abstracts the vendor, the same node binary works with different DDS implementations. Interoperability between vendors works over RTPS, but mixing vendors in one system is not recommended.

rclpy · talker.py

Your first publisher

import rclpy
from rclpy.node import Node
from std_msgs.msg import String

class Talker(Node):
    def __init__(self):
        super().__init__('talker')
        self.pub = self.create_publisher(
            String, 'chatter', 10)
        self.timer = self.create_timer(0.5, self.tick)
        self.count = 0

    def tick(self):
        msg = String(data=f'Hello {self.count}')
        self.pub.publish(msg)
        self.count += 1

def main():
    rclpy.init()
    rclpy.spin(Talker())
    rclpy.shutdown()

Read it top to bottom

  • Node gives the program a name in the graph
  • create_publisher takes type, topic, and QoS depth
  • The timer calls tick every 0.5 s
  • spin keeps the node alive and runs callbacks
Type this live rather than pasting. Point out that the topic name has no leading slash, so it is relative to the node namespace.

rclpy · listener.py

Your first subscriber

import rclpy
from rclpy.node import Node
from std_msgs.msg import String

class Listener(Node):
    def __init__(self):
        super().__init__('listener')
        self.sub = self.create_subscription(
            String, 'chatter', self.on_msg, 10)

    def on_msg(self, msg):
        self.get_logger().info(f'I heard: {msg.data}')

def main():
    rclpy.init()
    rclpy.spin(Listener())
    rclpy.shutdown()
